STEEL BALL RUN — WINDOWS PACKAGE

QUICK START
1. Extract this ZIP to a folder.
2. Double-click Launch-Steel-Ball-Run.bat, or open index.html in Edge, Chrome, or Brave.

NOTES
- This launches the HTML app in your default browser; it is not a compiled .EXE.
- Some browser APIs and media/file features behave differently when an HTML file is opened locally.
- The supplied HTML references cover.jpg, but no cover.jpg was included with the uploaded file; add it to this folder if you want that background image.
- The page loads jsmediatags from a CDN, so that feature needs an internet connection.
